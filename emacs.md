### Movements

^n ^p    # up/down
^f ^b    # left/right

^v Mv    # up/down page

^a ^e    # begin/end of line
Ma Me    # begin/end of sentence

See: [Moving Point](https://www.gnu.org/software/emacs/manual/html_node/emacs/Moving-Point.html)

### Basic

^x ^f    # find file
^x ^s    # save file

See: [File handling](https://www.gnu.org/software/emacs/manual/html_node/emacs/Files.html)

### Command line

Mx

See: [M-x](https://www.gnu.org/software/emacs/manual/html_node/emacs/M_002dx.html)

### Packages

Mx package-install RET evil RET

See: [Packages](https://www.gnu.org/software/emacs/manual/html_node/emacs/Packages.html)
