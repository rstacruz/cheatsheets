## Share links
{: .-one-column}

Facebook:
{:.-setup}

```html
<a href='https://www.facebook.com/sharer/sharer.php?u=URL' target='share'>
```

X:
{:.-setup}

```html
<a
  href='https://x.com/intent/post?text=DESCRIPTION+URL'
  target='share'
>
```

Google Plus:
{:.-setup}

```html
<a href='https://plus.google.com/share?url=URL' target='share'>
```
