## Shortcuts

<!-- {: .-three-column} -->

### Global

| Shortcut | Description |
| --- | --- |
| `^q` | Quit |

<!-- {: .-shortcuts} -->

See: [Global keys](https://github.com/rakshasa/rtorrent/wiki/User-Guide#global-keys)

### Main view

| Shortcut | Description |
| --- | --- |
| `bksp` | Add torrent |
| --- | --- |
| `->` | View download |
| --- | --- |
| `0` _-_ `9` | Change view |
| --- | --- |
| `^S` | Start download |
| `^K` | Stop and close a torrent |
| `^D` | Stop download (or remove stopped) |
| --- | --- |
| `+` _/_ `-` | Change priority |

<!-- {: .-shortcuts} -->

See: [Main view keys](https://github.com/rakshasa/rtorrent/wiki/User-Guide#main-view-keys)

### Throttling

#### Upload

| Shortcut | Description |
| --- | --- |
| `a` _/_ `s` _/_ `d` | Increase upload throttle by 5/50/500 KB |
| `z` _/_ `x` _/_ `c` | Decrease upload throttle by 5/50/500 KB |

<!-- {: .-shortcuts} -->

#### Download

| Shortcut | Description |
| --- | --- |
| `A` _/_ `S` _/_ `D` | Increase download throttle by 5/50/500 KB |
| `Z` _/_ `X` _/_ `C` | Decrease download throttle by 5/50/500 KB |

<!-- {: .-shortcuts} -->

See: [Throttling](https://github.com/rakshasa/rtorrent/wiki/User-Guide#throttling)

### Download view

| Shortcut | Description |
| --- | --- |
| `1` _/_ `2` | Adjust min uploads |
| `3` _/_ `4` | Adjust max uploads |
| `5` _/_ `6` | Adjust min peers   |
| `7` _/_ `8` | Adjust max peers   |

<!-- {: .-shortcuts} -->

See: [Download view keys](https://github.com/rakshasa/rtorrent/wiki/User-Guide#download-view-keys)
