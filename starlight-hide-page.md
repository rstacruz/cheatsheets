## Hiding pages
<!-- {: .-snippets} -->

### Hide the sidebar link
<!-- {: .-snippet} -->

```yaml
---
title: Deprecated API
sidebar:
  hidden: true
---
```
<!-- {: data-highlight="hidden: true"} -->

**Hides the link.** The page stays but its sidebar link is dropped; this applies to autogenerated groups, an explicit `sidebar` entry still shows, and the URL still builds. See [sidebar frontmatter](https://starlight.astro.build/reference/frontmatter/#sidebar).

### Drop the page from builds
<!-- {: .-snippet} -->

```yaml
---
title: Next release
draft: true
---
```
<!-- {: data-highlight="draft: true"} -->

**Drops it from builds.** The page still renders in `dev` with a draft notice, and is absent from the sidebar and search. See [draft](https://starlight.astro.build/reference/frontmatter/#draft).
