## Ordering links
<!-- {: .-snippets} -->

### Set an order number
<!-- {: .-snippet} -->

```yaml
---
title: Install
sidebar:
  order: 1
---
```
<!-- {: data-highlight="order: 1"} -->

**Sorts autogenerated links by number.** Lower numbers come first, and pages without `order` follow alphabetically; see [sidebar frontmatter](https://starlight.astro.build/reference/frontmatter/#sidebar).

### Pin the order by hand
<!-- {: .-snippet} -->

```js
sidebar: [
  'guides/install',
  'guides/deploy',
]
```
<!-- {: data-highlight="guides/install"} -->

**Lists links in the order written.** Slugs must match files under `src/content/docs/`; a renamed file leaves a dead link; see [sidebar](https://starlight.astro.build/guides/sidebar/).

### Collapse a group
<!-- {: .-snippet} -->

```js
sidebar: [
  {
    label: 'Reference',
    collapsed: true,
    items: ['reference/api'],
  },
]
```
<!-- {: data-highlight="collapsed: true"} -->

**Starts a group folded.** Groups are expanded by default, and `autogenerate.collapsed` does the same for generated subgroups; see [collapsing groups](https://starlight.astro.build/guides/sidebar/#collapsing-groups).
