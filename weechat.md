## Keys

<!-- {: .-three-column} -->

### Buffers

| Shortcut         | Description                      |
| ---              | ---                              |
| `A-S-U`          | Set unread marker on all buffers |
| ---              | ---                              |
| `^p, A-left`     | Switch buffer left               |
| `^n, A-right`    | Switch buffer right              |
| `A-a`            | Next buffer with activity        |
| `A-0...9`        | Switch buffers                   |
| ---              | ---                              |
| `F9` / `F10`     | Scroll buffer title              |
| `F11` / `F12`    | Scroll nick list                 |
| ---              | ---                              |
| `A-w A-Left`     | Switch windows                   |
| `A-w A-b`        | Balance windows                  |

<!-- {: .-shortcuts} -->

(`A-` is alt, `S-` is shift.)

See: [Buffers](https://weechat.org/files/doc/stable/weechat_user.en.html#key_bindings_buffers)

### Window commands

| Shortcut         | Description                      |
| ---              | ---                              |
| `/window splith` | Split horizontal                 |
| `/window splitv` | Split vertical                   |
| `/window zoom`   | Zoom                             |

See: [`/window` command](https://weechat.org/files/doc/stable/weechat_user.en.html#command_weechat_window)

### Search

| Shortcut | Description |
| --- | --- |
| `^s`              | Search      |
| `Enter` `^j` `^m` | Stop search |
